<h1 align="center">condition pour faire une pull request</h1>

- l'utilisation d'ia est prohibée dans vos Pull Request

## si c'est une texture

 - vérifiez que la texture n'a pas déjà été modifiée
 - la texture doit rester dans la [direction artistique](/README.md) du pack 
   
## si c'est une modification textuelle 
 - vérifiez bien que vous ne faites pas de fautes
 - la modification doit rester respectueuse des règles du [the create smp](https://thecreatesmp.fr/) qui s'appliquent aussi ici
